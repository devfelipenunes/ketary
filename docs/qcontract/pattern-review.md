# Contract design review cards

Use with the eight-field [canvas](contract-design.md). Each row is a
decision aid for existing Alpha predicates, not a new API or automatic
proof of sufficiency. Consult [reference](reference.md) for domain bounds.

| Pattern | Specify before coding | True defect to challenge | Variation to permit when intended | Avoid claiming |
|---|---|---|---|---|
| State preparation (StateEigen) | Zero input; signed independent commuting generators; target eigenspace | Wrong eigenvalue or missing correlation | Different circuit preparing same target | One arbitrary stabilizer identifies a state |
| Observable transformation (Transition) | Signed A and B; all inputs; U†BU=A | Sign reversal or wrong support | Common global phase; alternative gate sequence | One relation determines U |
| Invariant preservation (Transition) | Same signed observable on both sides; all inputs | Change of observable/sign | Changes to unobserved properties | Preservation of every observable |
| Clean workspace (CleanInput) | Initially clean wires; all remaining inputs arbitrary | Residual leakage into nonzero ancillas | Changes outside the clean subspace | Correct logical action |
| Equivalent implementation (Equivalent) | Independent reference; strict or common-phase policy | Wrong relative phase or action | Common global phase only if permitted | Hardware/transpilation equivalence in arbitrary domains |
| Subspace action (RelativeAction) | Independent reference; explicit clean ancillas; common phase | Logical phase error on superposition | Different action outside admitted subspace | Whole-register equality |
| Bipartition (Separable) | Zero input; partition and rank-one requirement | Entanglement crossing partition | Different product states | Correct target state |
| Measurement branch (ZBranch) | Zero input; specified Z outcome, probability and unnormalized observable | Wrong branch probability or expectation | Different behavior in unspecified branches | Arbitrary dynamic verification or normalized expectation |
| Weighted observable (SumTransition) | All inputs; exact bounded rational terms | Coefficient, sign or support error | Different decomposition with same sum | Arbitrary symbolic operator support |
| Noise contract (NoiseAfter) | Fixed finite Pauli channel following admitted Clifford circuit | Wrong mixture or transformed observable | Equivalent finite channel representation if admitted | Physical device noise coverage |
| Error correction (Correctable) | Supplied stabilizers and finite error set | Pair of errors violating Knill–Laflamme | Different circuit irrelevant to this circuit-independent predicate | Recovery implementation or fault tolerance |

The eleven review cards expand the ten grouped patterns in the canvas:
equivalence and subspace action need separate phase/scope decisions;
invariance and transformation share Transition. No predicate added.

## Anti-patterns and correction rules

| Symptom | Review action |
|---|---|
| Spec generated by measuring candidate | Establish independent target and freeze it before rewriting |
| Single input stands in for all inputs | Choose an admitted all-input property or explicitly narrow intent |
| All mutants must fail | Label true defects separately from permitted alternatives |
| More assertions assumed better | Check scope and implication; use redundant checks only for diagnosis |
| Component checks treated as composition proof | Verify combined circuit against overall requirement |
| Reuse a stale snapshot after edit | Prepare new source and retain revision/snapshot identity |
| Budget exhaustion treated as pass or refutation | Preserve INCONCLUSIVE; review domain/budget |
| Wire labels guessed from string order | Use explicit pauli_on indices and check actual width |
| Exact verifier assumed to cover physical execution | Document ideal source and separate hardware evidence |
